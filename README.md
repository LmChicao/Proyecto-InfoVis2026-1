# Proyecto-InfoVis2026-1 
## **Estudiantes:** Ninoska Cid, Lucas Chicao e Isidora Gomez

Proyecto que trata sobre la visualizacion de la contaminacion del aire a nivel global, 
aqui se identifican las principales causan junto a los paises que estan calificados con la peor calidad de aire

### **Datos:**
Tenemos un dataset con mas de 23 mil datos donde se registran los nombres de paises, ciudades y como los afecta los 4 principales contaminanes medidos, los cuales son Nitrogen Dioxide [NO2], Ozone [O3], Carbon Monoxide [CO] y Particulate Matter [PM2.5]. 


### Uso de IA

Durante el desarrollo de este proyecto se utilizó Claude como herramienta de apoyo técnico en situaciones puntuales, principalmente para resolver errores y mejorar fragmentos de código en JavaScript y HTML relacionados con la visualización de datos.
Fue útil para entender cómo estructurar ciertas funciones de JavaScript cuando los resultados no eran los esperados, ayudando a corregir bugs en el camino. Un ejemplo es con los sonidos del gráfico 1, los cuales luego se utilizaron en el gráfico 3, y también para resolver el problema de superposición de audios que aparecía en el gráfico 2.
